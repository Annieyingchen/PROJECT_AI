模型与设置

在项目 .env 中配置：

QA_LLM_BASE_URL=你的接口地址
QA_LLM_API_KEY=你的 API Key
QA_LLM_MODEL=模型名称

保存后重新运行 python workbench.py。API Key 只在 Python 服务端读取。

现有 Gradio 界面仍可通过 python app.py 启动。
